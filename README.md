# Modul CRUD Mahasiswa

Modul CRUD Mahasiswa adalah aplikasi web sederhana untuk mengelola data mahasiswa menggunakan **PHP Native, MySQL, dan MySQLi**. Aplikasi ini dibuat sebagai dasar Tugas Kelompok 1 pada materi Integrasi PHP & MySQL.

## Fitur

- Menambahkan data mahasiswa.
- Menampilkan daftar mahasiswa.
- Mengedit data mahasiswa.
- Menghapus data mahasiswa.
- Mencari mahasiswa berdasarkan NIM, nama, program studi, atau email.
- Menampilkan data dalam beberapa halaman (pagination).
- Memvalidasi input dan menerapkan prepared statement untuk membantu menjaga keamanan data.

## Teknologi

- PHP Native
- MySQL
- MySQLi
- HTML
- CSS

## Tujuan

Aplikasi ini bertujuan untuk menerapkan konsep CRUD (*Create, Read, Update, Delete*) serta memahami integrasi PHP dengan database MySQL dalam pengembangan aplikasi web.
